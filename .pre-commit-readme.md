# Pre-commit Setup Guide

This repository uses [pre-commit](https://pre-commit.com/) to ensure code quality and consistency.

## Installation

Pre-commit is already configured in this repository. If you're setting up a new development environment:

### macOS (using Homebrew)
```bash
brew install pre-commit
```

### Linux/Windows (using pip)
```bash
pip install pre-commit
```

## Setup

After installing pre-commit, run the following command in the repository root:

```bash
pre-commit install
```

This installs the git hooks that will run automatically before each commit.

## What Gets Checked

The pre-commit hooks will automatically:

1. **General File Checks**
   - Remove trailing whitespace
   - Fix end of file issues
   - Validate YAML files
   - Check for large files (>1MB)
   - Detect merge conflicts
   - Check for case conflicts
   - Normalize line endings to LF
   - Detect private keys

2. **Go-Specific Checks**
   - Format code with `go fmt`
   - Organize imports with `go imports`
   - Run `go vet` for suspicious constructs
   - Run `go mod tidy` to clean dependencies
   - Run `golangci-lint` for comprehensive linting

## Usage

### Automatic Checks
Pre-commit hooks run automatically when you commit:
```bash
git commit -m "your commit message"
```

If any checks fail, the commit will be blocked and files may be auto-fixed. Review the changes and commit again.

### Manual Checks

Run on all files:
```bash
pre-commit run --all-files
```

Run on specific files:
```bash
pre-commit run --files path/to/file.go
```

Run a specific hook:
```bash
pre-commit run go-fmt --all-files
```

### Skip Hooks (Use Sparingly)

If you need to skip hooks for a specific commit (not recommended):
```bash
git commit -m "your message" --no-verify
```

## Updating Hooks

To update to the latest versions of the hooks:
```bash
pre-commit autoupdate
```

## Troubleshooting

### Hooks are slow
Pre-commit caches hook environments. The first run is slower as it sets up the environments.

### Golangci-lint not found
Install golangci-lint:
```bash
# macOS
brew install golangci-lint

# Linux
curl -sSfL https://raw.githubusercontent.com/golangci/golangci-lint/master/install.sh | sh -s -- -b $(go env GOPATH)/bin
```

### Goimports not found
Install goimports:
```bash
go install golang.org/x/tools/cmd/goimports@latest
# Make sure $(go env GOPATH)/bin is in your PATH
export PATH=$PATH:$(go env GOPATH)/bin
```

### Clean hook cache
If you encounter issues:
```bash
pre-commit clean
pre-commit install --install-hooks
```

### Pre-commit reports many errors
The current configuration will report existing code quality issues but won't block commits. You can:
1. Fix issues gradually as you work on related code
2. Run `pre-commit run --all-files` to see all issues
3. Adjust [.golangci.yml](.golangci.yml) to make checks more/less strict
