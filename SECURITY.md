# Security Policy - Hypasis Sync Protocol

## Supported Versions

The Hypasis team provides security updates for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1.0 | :x:                |

## Reporting a Vulnerability

We take the security of the Hypasis Sync Protocol seriously. If you believe you have discovered a vulnerability or security issue, please **do not open a public GitHub issue**.

### How to Report

Please report security vulnerabilities directly to the Hypasis security team:

* **Email**: `security@hypasis.io` (or `team@hypasis.io`)
* **PGP Key**: Available upon request.

Please include as much of the following information as possible to help us understand and address the issue:
1. Type of issue (e.g., buffer overflow, integer overflow, unauthorized RPC access, cryptographic bypass).
2. Full steps or proof-of-concept (PoC) script to reproduce the issue.
3. Affected components (`pkg/checkpoint`, `pkg/p2p`, `pkg/auth`, etc.).
4. Potential impact of the vulnerability.

### Response Timeline

* **Initial Response**: Within 24 hours of receiving the report.
* **Triage & Status Update**: Within 72 hours.
* **Patch Release**: High severity issues will be patched and released as an advisory within 7 days.

## Preferred Disclosure & Bounty

We adhere to standard coordinated vulnerability disclosure practices. Once a fix is verified and deployed, security researchers will be acknowledged in our release release notes.
